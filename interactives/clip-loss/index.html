Compare both retrieval directions.

Both probability matrices update after every gradient step. The diagonal entries are the probabilities of the correct partners.

Each row on the left sums to 1. Each column on the right sums to 1.

Put the steps together.

  1. Take N matching image and text pairs.
  2. Encode both modalities into vectors and normalize each vector.
  3. Compare every image with every text: N² cosine similarities.
  4. Scale by temperature, then apply softmax across rows and down columns.
  5. Take the negative log of each correct match’s probability; average both directions.
  6. Backpropagate through both encoders. Repeat with the next batch.

Training makes matched image and text representations easier to distinguish from mismatched pairs.

Down columns ↓Qᵢⱼ = exp(Lᵢⱼ) / ∑ₖ exp(Lₖⱼ)

Image → Textℒᵢ→ₜ = −(1/N) ∑ᵢ log Pᵢᵢ

Text → Imageℒₜ→ᵢ = −(1/N) ∑ᵢ log Qᵢᵢ

Symmetric CLIP lossℒ = ½ (ℒᵢ→ₜ + ℒₜ→ᵢ)

Implementation uses exp(x − max(x)) for numerical stability. Extended precision displays eight decimal places; calculations always use full JavaScript floating-point precision.
